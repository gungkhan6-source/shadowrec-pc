================================================================================
                            ADMINISTRATOR PRIVILEGES
================================================================================

NovaRec Studio requires administrator privileges to function correctly.
This is needed for:

  - DLL injection into game processes (game capture feature)
  - Reading process modules and memory for graphics API detection
  - Creating shared memory regions for frame transfer
  - Accessing system audio devices via WASAPI

NovaRec Studio does not modify any game files, does not send data to remote
servers without your consent, and does not use anti-cheat bypass techniques.
The software is designed for legitimate recording and streaming purposes only.

================================================================================
                            ANTI-CHEAT WARNING
================================================================================

Some online games employ anti-cheat systems (Easy Anti-Cheat, BattlEye, vgc,
Vanguard, etc.) that may flag DLL injection as suspicious behavior. Using
NovaRec Studio's game capture feature in such games may result in account
suspension or bans.

NovaRec Studio is intended for use with:
  - Single-player games
  - Games without active anti-cheat
  - Game development testing
  - Personal streaming and content creation

The user assumes all responsibility for any consequences arising from the use
of NovaRec Studio with online games.
